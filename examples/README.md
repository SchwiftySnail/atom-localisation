# Recorded example run

Read [the results report](report.md) for the figures, per-method errors and model assumptions.

This run used 100 trials for each of 72 conditions: three spot widths, three positions, five Gaussian noise levels and three Poisson count scales. It produced 7,200 simulated images and 28,800 estimates. All estimates succeeded under the recorded configuration; the implementation also records failures when they occur.

These files were generated from scientific source commit `13f4481`, before the repository's publication documentation was added. [metadata.json](metadata.json) records the exact configuration, seed, dependency versions and Git state. [summary.csv](summary.csv) contains all 288 per-method summaries.

To regenerate the run from the repository's complete-project branch:

```sh
python3 run_project.py --noise-models gaussian poisson --output outputs/experiment
```

The full per-trial CSV is generated by this command and is not included in this small example folder. No experimental images or measurements are included; all images are synthetic.
